# RC Aerobatic Aircraft

## Overview

This project is a foam board RC aerobatic aircraft designed for agile flight maneuvers and advanced flight training. The aircraft was built to explore aircraft design, aerodynamics, and radio-controlled flight systems.

## Components

* 5 mm Foam Board Airframe
* RS2205 2300KV Brushless Motor
* Skywalker 30A ESC
* 4 × SG90 Servo Motors
* FlySky FS-CT6B 2.4 GHz 6-Channel Transmitter
* FS-R6B Receiver
* 5×4.5 Propeller

## Features

* Lightweight foam board construction
* High power-to-weight ratio
* Responsive control surfaces
* Suitable for aerobatic maneuvers
* Easy maintenance and repair

## Flight Controls

* Aileron
* Elevator
* Rudder
* Throttle
